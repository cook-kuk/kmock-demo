# K-MOCK 60

한국어 모의시험 60문항을 포함한 단일 HTML 앱입니다.

## 실행

GitHub Pages에서 열거나 `index.html`을 내려받아 브라우저에서 엽니다. 설치나 서버가 필요하지 않습니다.

## 구성

1~6급 각 10문항: 읽기 38, 듣기 14, 쓰기 8. 급수·영역 선택, 제한 시간, 답안 저장, 표시, 객관식 채점, 결과 JSON 내보내기를 지원합니다.

## 정답 및 음성

원본에 정답표가 없어 객관식 정답·해설은 AI 풀이 기반 임시 자료입니다. 쓰기는 답안을 보관하며 자동 채점하지 않습니다. 듣기는 기기의 한국어 합성음 또는 대본 연습을 사용합니다. 공식 TOPIK 시험이나 성적 서비스가 아닙니다.

답안은 현재 브라우저에 저장되며 서버로 전송하지 않습니다. 생성기·Critic 연결은 포함하지 않습니다. 자세한 사용법은 README_KO.txt를 참고하세요.
