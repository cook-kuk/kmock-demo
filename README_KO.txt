K-MOCK 60 오프라인 한국어 모의시험

실행
1. ZIP 파일의 압축을 해제합니다.
2. index.html을 Chrome, Edge 또는 Safari에서 엽니다.
3. 급수·영역·시간을 선택하고 시험을 시작합니다.
설치·로그인·서버 실행이 필요 없습니다. index.html 안에 화면, 코드, 60문항이 모두 포함되어 있습니다. questions.json은 검토·수정용 사본이며 실행에 필요하지 않습니다.

문항 출처
사용자가 제공한 KMOCK_60_Complete_Sample_Final.docx (2026-10-28 시연본).
1~6급 각각 10개: 읽기 38개, 듣기 14개, 쓰기 8개.
문제·지문·선택지·듣기 대본은 원문에서 추출했습니다. 밑줄 4곳과 삽입문 보기 3개를 보존했습니다. 급수는 목표 수준이며 실제 난이도는 검증 전입니다. 공식 TOPIK 기출문항이나 공식 성적 서비스가 아닙니다.

정답과 채점
원본 Word에는 정답표·해설이 없습니다.
객관식 52문항의 정답과 해설은 AI가 지문·대본을 풀이해 작성한 임시 자료입니다. 원본 정답표와 대조된 확정 정답이 아닙니다.
객관식은 각 1문항으로 계산하며 정답률을 표시합니다. 미응답 객관식은 오답으로 계산합니다. 쓰기 8문항은 답안만 보관하고 채점 대기로 표시하며 객관식 정답률에서 제외합니다. 공식 점수·급수 판정은 하지 않습니다.

듣기
원본에는 녹음 음원이 없습니다.
기기에 이미 설치된 오프라인 한국어 합성음이 있으면 '듣기 재생'을 사용할 수 있습니다. 브라우저·운영체제에 따라 한국어 음성이 없을 수 있습니다. 이 경우 '대본으로 연습'을 누르면 원본 대본을 읽을 수 있습니다. 대본 열람 문항 수는 결과에 표시합니다. 합성음과 대본 연습은 실제 청취평가와 다릅니다.

저장
답안과 최근 30회 기록은 현재 브라우저의 localStorage 저장을 시도합니다. 파일 이동·이름 변경·다른 브라우저 사용·시크릿 모드·저장 설정에 따라 기록이 유지되지 않을 수 있습니다.
중요한 답안은 제출 후 '결과 JSON 내려받기'로 보관하세요.
진행 중인 시험의 제한 시간은 화면을 닫아도 계속 계산되며, 종료 시각이 지난 뒤 다시 열면 자동 제출됩니다.
별도 서버나 분석 도구로 답안을 보내지 않습니다. 외부 폰트·스크립트를 불러오지 않습니다. 음성 기능은 브라우저가 로컬 음성으로 표시한 한국어 음성만 사용합니다.

포함된 기능
60문항 기본 수록, 급수·영역별 선택, 1~240분 제한 시간, 문항 이동, 나중에 보기 표시, 답안 저장, 자동 제출, 임시 정답 기반 객관식 채점, 해설 복습, 쓰기 답안 보관, 결과 파일 다운로드.
문항 생성기·Critic·쓰기 AI 채점은 연결하지 않았습니다.

검증 범위
문항 수·영역 수·급수별 수·대본·보기·밑줄 보존과 데이터 채점 검사를 완료했습니다. 실제 HTML의 스크립트를 DOM 대체 환경에서 실행하여 기본 로딩·영역 선택·문항 표시·저장·시간 종료·채점 동작을 확인했습니다.
이 작업 환경의 브라우저는 file:// 주소를 허용하지 않아, 실제 데스크톱 더블클릭 실행과 기기별 한국어 음성 출력은 여기에서 확인하지 못했습니다.
